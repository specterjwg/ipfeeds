A community-driven Cyber Threat Intelligence (CTI) repository containing categorized Indicators of Compromise (IOCs) for defensive security operations.

IPFeeds is a centralized repository of malicious IP addresses collected from multiple public threat intelligence sources and internally validated data.
Feeds are updated periodically as new malicious IP addresses become available.

The repository is designed to simplify integration into:

Firewalls
SIEM platforms
IDS/IPS
EDR/XDR
SOAR
WAF
DNS Sinkhole
Proxy Servers
